Chess Coach (Stockfish + LLM Commentary)
A small project I built for fun to explore "explainable chess": Stockfish provides the best line + evaluation, and an LLM turns that into human-friendly commentary for each move (PGN input).
Built as a simple API + web app. It’s intentionally lightweight, but it’s complete enough to run locally and extend. This was made in a day.

It’s not trying to outperform Chess.com’s Game Review of course, it’s my attempt at a lightweight 'commentary layer' on top of Stockfish, focused on explainability and UX.
